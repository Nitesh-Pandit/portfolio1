## 🚀 Quick Start

```bash
# Clone & Install
git clone https://github.com/Nitesh-Pandit/portfolio1
cd portfolio
npm install

# Development
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

**Live at:** `http://localhost:5173`

## 🔧 Deployment

### Vercel (Recommended)
```
npm i -g vercel
vercel --prod
```

### Netlify
Drag `dist/` folder to [netlify.com/drop](https://netlify.com/drop)

### GitHub Pages
```
npm run build
# Deploy dist/ to gh-pages branch
```
